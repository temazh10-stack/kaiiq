# Project Kai

Учебный интернет-магазин винтажной одежды на PHP, MySQL, HTML, CSS и JavaScript.

## Возможности

Каталог с фильтрами и сортировкой, карточки товаров, регистрация и вход,
личный кабинет, избранное, корзина, оформление заказов и отзывы.
В административной панели доступны восемь таблиц и пять SQL-представлений.
Printful API используется для справочника стран и регионов доставки.

## Требования

PHP 8.x с PDO MySQL, mbstring, OpenSSL и включенным allow_url_fopen;
MySQL или MariaDB; Apache (например, Open Server Panel).
GD нужен только для необязательного скрипта оптимизации изображений.
Сборка через npm или Composer не требуется.

## Запуск в Open Server Panel

1. Скопируйте проект в `C:/OSPanel/domains/localhost/kaii` или другую папку
   внутри корня локального веб-сервера. Запустите Apache и MySQL.
2. Создайте копии конфигураций в PowerShell из корня проекта:

   ```powershell
   Copy-Item includes/config.example.php includes/config.php
   Copy-Item includes/printful_config.example.php includes/printful_config.php
   ```

3. Укажите в `includes/config.php` локальные DB_HOST, DB_NAME, DB_USER и DB_PASS.
   Не добавляйте этот файл в Git.
4. В phpMyAdmin импортируйте `sql/schema.sql`. Скрипт создает базу
   `project_kai_db`, таблицы, учебные данные и пять представлений.
   Импорт выполняйте только в отдельную учебную базу: скрипт удаляет
   одноименные таблицы и создает их заново. Существующую рабочую базу
   сначала сохраните отдельно. `sql/translate_ru.sql` предназначен для
   старых англоязычных данных; для новой русской схемы он не требуется.
5. Откройте `http://localhost/kaii/index.php`. При другом размещении
   замените путь в адресе. BASE_URL определяется автоматически.
6. Создайте новый аккаунт на странице регистрации с собственным паролем.
   Учебные учетные записи из SQL имеют отключенные пароли.
7. Чтобы назначить своего локального администратора, выполните в phpMyAdmin
   следующий запрос, заменив email на адрес созданного аккаунта:

   ```sql
   UPDATE user SET role = 'admin' WHERE email = 'your-email@example.com';
   ```

   Выйдите и войдите снова. Откроется административная панель.

## Настройка справочника доставки

При наличии собственного Printful API key укажите его в
`includes/printful_config.php`. Файл исключен из Git. Сервер должен иметь
доступ по HTTPS к API, корректное хранилище сертификатов и право записи
в `cache`. Список стран кэшируется на семь суток. Без ключа или доступного
справочника предусмотрен ручной выбор зоны доставки.
Тарифы доставки вычисляет магазин, а не Printful.

## Структура

- `admin/` — управление таблицами и просмотр SQL-представлений.
- `api/` — переключение избранного.
- `cabinet/` — профиль, история заказов, избранное.
- `includes/` — подключение БД, общие функции, шаблоны и API.
- `assets/` — стили, JavaScript и изображения.
- `sql/` — схема, учебные данные и представления.
- `scripts/` — вспомогательный скрипт оптимизации изображений.
- `cache/` — локальный кэш, исключенный из Git.

## Проверка после запуска

Зарегистрируйте покупателя, измените город в профиле, добавьте товар в
избранное и корзину, оформите учебный заказ. Проверьте заказ в кабинете
и оставьте отзыв. Под администратором создайте временный бренд, измените
его название и удалите; откройте все пять представлений.

## Известные ограничения учебной версии

Ссылки «Забыли пароль?» и «Подробнее» у заказа пока являются заглушками.
Контактная форма проверяет данные и показывает подтверждение, но не
отправляет письмо и не сохраняет обращение. Правовые и социальные ссылки
также не ведут на отдельные страницы. Онлайн-оплата не реализована.
На 02.10.2026 эти ограничения зафиксированы при функциональном тестировании.

## Конфиденциальные данные

Действующие настройки БД, ключ API, кэш и пароли исходного локального сайта
не включены в репозиторий. Данные в SQL являются учебными примерами.
Публикуемая копия не содержит изменений действующей базы сайта.
